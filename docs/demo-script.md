# TIMBRE LinkedIn Demo Script

## Format

- Length: 60–75 seconds
- Frame: 16:9 screen recording, app window centered, system notifications hidden
- Audio: record app output plus voiceover; use headphones to prevent microphone bleed
- Demo prompt: `A dark, cinematic pad with slow movement, wide stereo space, and a little analog warmth`

## Before Recording

1. Build and open the audio-enabled standalone target, not the UI-only shell.
2. Confirm audio output in `Settings → Audio device → Open`.
3. Start from a clean session with the simple play surface visible.
4. Keep the prompt text ready to paste, but do not paste it until recording starts.
5. If Gemini generation is unavailable, use the seeded quick-start patch and narrate the same interaction without claiming live generation.

## Shot List And Voiceover

| Time | On screen | Voiceover |
|---|---|---|
| 0:00–0:05 | TIMBRE idle. Move cursor into prompt field. | “Most synthesizers make you think in parameters first. TIMBRE starts with the sound you’re imagining.” |
| 0:05–0:13 | Enter the demo prompt and submit with Enter. | “I’ll describe a dark, cinematic pad with movement, width, and warmth.” |
| 0:13–0:23 | Let generation finish. Keep the generated patch and response visible. | “The agent translates that description into a playable synthesizer patch.” |
| 0:23–0:32 | Play several notes on the on-screen keyboard, or use the mapped QWERTY keys. | “No samples are being triggered here. This is a real polyphonic synth responding in real time.” |
| 0:32–0:42 | Turn `BRIGHTNESS` upward, then `WOBBLE` slightly. Play another chord. | “The generated sound is only the starting point. These macros give me expressive controls without making me hunt through a wall of knobs.” |
| 0:42–0:50 | Enter `Make it brighter and give it more air` and submit. | “I can refine it conversationally instead of rebuilding the patch from scratch.” |
| 0:50–0:59 | Play the updated sound. Briefly toggle A/B if both slots are ready. | “The second pass keeps the musical intent, while changing the character.” |
| 0:59–1:08 | Click `Open the hood`. Slowly pan across oscillators, filter, envelopes, and effects. | “And when I want detail, every generated decision is exposed as a real control: oscillators, filter, modulation, and effects.” |
| 1:08–1:15 | Close hood. End on TIMBRE wordmark and a final chord. | “Describe it. Hear it. Then make it yours. This is TIMBRE.” |

## Recording Notes

- Pause 2–3 seconds after each prompt so generation and UI transitions are visible.
- Keep cursor movements slow and deliberate. Avoid crossing the prompt text while speaking.
- Use one chord or three-note phrase, not random key mashing.
- If A/B is not ready, skip the toggle and spend the time on the updated sound.
- If generation fails, do not cut around it in the live take. Restart with the quick-start patch or use a clearly labelled prerecorded generation shot.
